## 📋 Что нужно сделать для завершения

### 1. Протестировать сборку документации локально

```bash
# Установить зависимости для документации
uv sync --group docs

# Собрать документацию
make docs

# Проверить, что сборка прошла успешно
ls -la docs/_build/html/index.html
```

Если сборка прошла успешно, вы увидите HTML файлы в `docs/_build/html/`.

### 2. Сгенерировать отчеты об экспериментах

```bash
# Убедитесь, что у вас есть эксперименты в MLflow
# Если экспериментов нет, сначала запустите обучение:
# dvc repro train_model

# Сгенерировать отчеты
PYTHONPATH=. uv run python scripts/generate_experiment_report.py \
    --tracking-uri mlruns \
    --experiment-name wine-quality \
    --output-dir reports/experiments
```

Проверьте, что созданы файлы:
- `reports/experiments/experiment_report.md`
- `reports/experiments/experiment_results.csv`
- `reports/experiments/figures/*.png`

### 3. Настроить GitHub Pages (если еще не настроено)

1. Перейдите в настройки репозитория на GitHub: Settings > Pages
2. В разделе "Source" выберите "GitHub Actions"
3. Сохраните изменения

### 4. Закоммитить и запушить изменения

```bash
# Добавить все новые файлы
git add .

# Закоммитить
git commit -m "ДЗ 6: Добавлена документация и система генерации отчетов"

# Запушить в репозиторий
git push origin main  # или master, в зависимости от вашей ветки
```

### 5. Проверить работу GitHub Actions

1. Перейдите на вкладку "Actions" в вашем репозитории на GitHub
2. Дождитесь завершения workflow "Build and Deploy Documentation"
3. Проверьте, что документация опубликована на GitHub Pages
