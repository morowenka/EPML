#### 1.3 Автоматическая генерация документации

✅ **Выполнено:** Настроена автоматическая генерация документации.

**Реализация:**
- Добавлены зависимости Sphinx в `pyproject.toml`:
  ```toml
  [dependency-groups]
  docs = [
      "sphinx==7.2.6",
      "sphinx-rtd-theme==2.0.0",
      "sphinx-autodoc-typehints==1.25.2",
  ]
  ```
- Добавлены команды в `Makefile`:
  - `make docs` - Собрать документацию
  - `make docs-clean` - Очистить собранную документацию
  - `make docs-serve` - Собрать и запустить локальный сервер

**Использование:**
```bash
# Установить зависимости
uv sync --group docs

# Собрать документацию
make docs

# Или вручную
cd docs
uv run sphinx-build -b html . _build/html
```

### 3. Отчеты об экспериментах (2 балла)

#### 3.1 Создание отчетов в формате Markdown

✅ **Выполнено:** Создан скрипт `scripts/generate_experiment_report.py` для генерации отчетов.

**Функциональность:**
- Загрузка экспериментов из MLflow
- Генерация Markdown отчета с:
  - Общей статистикой по экспериментам
  - Статистикой по метрикам
  - Статистикой по типам моделей
  - Топ-5 моделями по каждой метрике
  - Ссылками на графики и таблицы

#### 3.2 Графики и визуализации результатов

✅ **Выполнено:** Скрипт генерирует три типа графиков:

1. **Сравнение метрик по типам моделей** (`metrics_by_model_type.png`)
   - Box plots для каждой метрики по типам моделей
   
2. **Распределение метрик** (`metrics_distribution.png`)
   - Гистограммы распределения метрик
   - Отметка среднего значения
   
3. **Топ модели** (`top_models.png`)
   - Топ-10 моделей по каждой метрике
   - Горизонтальные bar charts

**Использование:**
```bash
PYTHONPATH=. uv run python scripts/generate_experiment_report.py \
    --tracking-uri mlruns \
    --experiment-name wine-quality \
    --output-dir reports/experiments
```

#### 3.3 Сравнительные таблицы экспериментов

✅ **Выполнено:** Скрипт создает сравнительную таблицу в формате CSV.

**Содержание таблицы:**
- ID запуска
- Имя запуска
- Статус
- Все метрики (accuracy, f1_macro и др.)
- Тип модели
- Основные параметры

**Формат:** `experiment_results.csv` в директории `reports/experiments/`

#### 3.4 Автоматическая генерация отчетов

✅ **Выполнено:** Скрипт полностью автоматизирован.

**Возможности:**
