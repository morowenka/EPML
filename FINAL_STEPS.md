## 🚨 Возможные проблемы и решения

### Проблема: GitHub Actions не запускается
**Решение:** Убедитесь, что:
- Файл `.github/workflows/docs.yml` существует
- Вы запушили изменения в main/master ветку
- В настройках репозитория включены GitHub Actions

### Проблема: Документация не публикуется на GitHub Pages
**Решение:**
1. Проверьте, что в Settings > Pages выбран источник "GitHub Actions"
2. Убедитесь, что workflow выполнился успешно
3. Подождите несколько минут - публикация может занять время

### Проблема: Скрипт генерации отчетов не работает
**Решение:**
- Убедитесь, что у вас есть эксперименты в MLflow
- Проверьте правильность имени эксперимента (`--experiment-name`)
- Проверьте путь к MLflow (`--tracking-uri`)
