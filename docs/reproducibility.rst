Воспроизводимость
=================

Для обеспечения воспроизводимости результатов проект использует:

Версионирование данных
----------------------

Данные версионируются через DVC:

.. code-block:: bash

   dvc pull  # Скачать данные
   dvc repro  # Воспроизвести пайплайн

Версионирование моделей
-----------------------

Модели версионируются через:
- MLflow Model Registry
- ClearML Model Registry
- DVC (локально)

Фиксация зависимостей
---------------------

Зависимости фиксируются в `uv.lock`:

.. code-block:: bash

   uv sync --frozen  # Использовать зафиксированные версии

Конфигурация
------------

Все параметры экспериментов хранятся в конфигурационных файлах:
- `conf/config.yaml` - основная конфигурация
- `params.json` - параметры для DVC

Случайные числа
---------------

Для воспроизводимости используется фиксированный `random_state`:

.. code-block:: yaml

   train:
     random_state: 13

Воспроизведение результатов
----------------------------

1. Клонируйте репозиторий:

.. code-block:: bash

   git clone <repository-url>
   cd EPML

2. Установите зависимости:

.. code-block:: bash

   uv sync --frozen

3. Скачайте данные:

.. code-block:: bash

   dvc pull

4. Запустите пайплайн:

.. code-block:: bash

   dvc repro

5. Проверьте результаты:

.. code-block:: bash

   # Просмотр метрик
   cat reports/metrics.json

   # Просмотр экспериментов в MLflow
   mlflow ui
